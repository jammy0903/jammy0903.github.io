# desk

반투명 · 항상 위 · 작은 창 하나에 게임 네 개.
파이썬 표준 라이브러리(tkinter)만 쓴다. 설치할 것 없음.

```bash
python3 desk.py
```

영어판은 `L` 키 한 번이면 된다 → [README.en.md](README.en.md)

윈도우에서는 **`desk.bat`을 더블클릭**하면 된다. 콘솔 창 없이 게임 창만 뜬다.
(폴더째 윈도우 쪽으로 복사해 두고 쓰는 게 편하다 — 예: `C:\Users\<이름>\desk\`)

바로 띄우고 싶으면 `desk.bat` 바로가기를 만들어
`Win + R` → `shell:startup` 폴더에 넣으면 로그인할 때 자동 실행된다.

## 조작

| 키 | 하는 일 |
| --- | --- |
| `ESC` | **작업표시줄로 내리기.** 프로그램은 계속 돌고 판·점수 그대로 |
| `F8` | **작업표시줄에서 다시 꺼내기** (전역 단축키, 윈도우) |
| `H` | 투명도만 0으로. 한 번 더 누르면 복귀 (창은 그 자리에 그대로) |
| `M` | **게임 고르기 화면** (`↑` `↓` + `Enter`, 클릭도 됨). 프로그램을 켜면 이 화면부터 |
| `1` ~ `9` | 게임 바로 가기 |
| `[` `]` | 흐리게 / 진하게 — 메뉴 화면의 **투명도 바를 마우스로 끌어도** 된다 |
| `L` | 한국어 / English 전환 |
| `R` | 지금 게임만 새로 시작 (레벨 게임은 이 판만 다시) |
| `,` `.` | **판 넘기기** (레벨 있는 게임). `PageUp`/`PageDown` 은 10판씩 |
| `Ctrl+Q` | 종료 (창의 X 버튼도 종료) |

**`ESC`는 종료가 아니라 내리기다.** 급하게 눌러도 판이 날아가지 않는다.
끄려면 `Ctrl+Q` 또는 창의 X 버튼. 어느 쪽이든 진행 상황은 저장된다.

`ESC`(작업표시줄)와 `H`(투명도 0)는 쓰임이 다르다.

- `ESC` — 화면에서 완전히 치운다. 다른 창이 그 자리를 덮는다. 복귀는 `F8` 또는 작업표시줄 클릭.
- `H` — 창은 그 자리에 그대로 있고 보이지만 않는다. 키 입력도 계속 받아서 `H` 한 번이면 즉시 돌아온다. 더 빠르다.

## 게임 고르기 (9개)

프로그램을 켜면 **고르는 화면**이 먼저 뜬다. 게임 이름과 함께 최고 기록,
그리고 하던 판이 있으면 그 점수가 같이 보인다.

- `↑` `↓` 로 옮기고 `Enter`. 마우스로 클릭해도 된다.
- 숫자 `1`~`4`를 누르면 메뉴를 거치지 않고 바로 그 게임으로 간다.
- 게임 도중에 `M`을 누르면 다시 이 화면이 뜬다. **메뉴가 떠 있는 동안 게임 시간은 멈춘다**
  (테트리스 블록이 안 떨어지고, 수박도 안 굴러간다).
- 어느 게임으로 옮겨도 **네 판이 각자 그대로 남아 있다.** 다시 돌아오면 하던 자리부터다.

게임별 조작:

| # | 게임 | 조작 |
| --- | --- | --- |
| 1 | 테트리스 | `←` `→` 이동 · `↑` 회전 · **`Z` 반시계** · `↓` 소프트드롭 · `Space` 하드드롭 |
| 2 | 수박게임 | `←` `→` 위치 · `Space` 떨어뜨리기 |
| 3 | 뿌요뿌요 | `←` `→` 이동 · `↑` 회전 · **`Z` 반시계** · `↓` 내리기 · `Space` 떨구기 |
| 4 | 2048 | 방향키 |
| 5 | Threes! | 방향키 |
| 6 | Triple Town | 방향키 커서 · `Space` 놓기 · `S` 보관칸 교체 |
| 7 | 네모로직 | 방향키 커서 · `Space` 칠하기 · `X` 표시 · **`S` 판 크기** · `Enter` 다음 판 |
| 8 | Flood It | `←` `→` 색 고르기 · `Space` 칠하기 · `Enter` 다음 단계 |
| 9 | 소코반 | 방향키로 밀기 · `U` 무르기 · `Enter` 다음 판 |

## 레벨

| 게임 | 판 수 | 어떻게 어려워지나 |
| --- | --- | --- |
| 네모로직 | **크기마다 500판** | `S` 로 10x10 · 15x15 · 20x20 선택. 뒤로 갈수록 밀도가 애매해져 힌트가 약해진다 |
| 소코반 | **200판** | 방이 커지고 상자가 2 → 4개, 흐트러진 정도가 깊어진다 |
| Flood It | **60단계** | 11x11 5색 → 20x20 6색, 허용 횟수의 여유가 5 → 1로 줄어든다 |
| 테트리스 | 끝없음 | 8줄마다 한 단계. 빨리 떨어지고 점수 배수가 커진다 |
| 뿌요뿌요 | 끝없음 | 24개 터뜨릴 때마다 한 단계. 색이 5개다 |
| 나머지 | 끝없음 | 판이 꽉 찰 때까지 |

레벨이 있는 세 게임에서 **`R`은 "이 판만 다시"다.** 어렵게 올라온 레벨은 그대로 남고,
**`,` `.` 로 원하는 판까지 바로 건너뛸 수 있다.** 500판을 넣어 놓고 한 판씩만
넘어갈 수 있으면 뒷판을 볼 길이 없다.

네모로직은 크기(10 · 15 · 20)마다 진행도를 **따로** 센다. 20x20 하다가 10x10 갔다
와도 하던 판 그대로다.

판을 파일로 500개 저장해 두지 않고 **레벨 번호를 씨앗으로 그때그때 만든다.**
같은 레벨은 언제 켜도 같은 판이고, 프로그램 크기는 그대로다.
중요한 건 만들어 낸 판이 **반드시 풀리느냐**인데, 게임마다 다르게 보장한다.

- **네모로직** — 찍지 않고 줄 논리만으로 풀리는지 풀이기를 돌려서 통과한 판만 낸다.
  500판 전부 확인했다(판당 0.1초 이내).
- **소코반** — 거꾸로 만든다. 다 푼 모습에서 상자를 *당겨서* 흐트러뜨리므로
  당긴 순서를 뒤집으면 그대로 정답이다. 게임 중에는 탐색을 돌리지 않는다.
- **Flood It** — "매번 가장 많이 먹는 색"으로 푸는 수를 세서, 거기에 여유를 더한 값을
  허용 횟수로 쓴다. 사람이 실제로 쓸 수 있는 전략이라 못 깨는 판이 없다.

## 기록

`~/.deskgames.json` 하나에 아홉 게임의 진행 판·최고점·투명도·언어·마지막에 보던 게임이 들어간다.
사용자 구분도 로그인도 없다.

- 최고 기록은 **점수가 오를 때마다** 갱신되고, 판을 새로 시작하거나(`R`) 점수가 내려가도 남는다.
- 저장 시점: 창을 내릴 때 · 게임을 바꿀 때 · 종료할 때 · 그리고 10초마다 자동으로.
- 임시 파일에 쓰고 바꿔치기하는 방식이라, 쓰는 도중에 프로그램이 죽어도 기존 기록이 깨지지 않는다.

파일을 지우면 전부 초기화된다.

## 규칙 메모

- **뿌요뿌요** — 6x12, 색 5개. 같은 색 4개가 상하좌우로 붙으면 터지고, 위가 내려앉아 연쇄된다.
  연쇄가 길수록 배수가 커진다.
- **2048** — 표준. 새 타일은 2가 90% / 4가 10%.
- **네모로직** — 다 맞춘 줄의 힌트는 흐려진다. 판 크기만큼 점수를 준다.
- **Flood It** — 왼쪽 위와 이어진 내 영역은 흰 테두리로 표시된다.
  적게 쓸수록 점수가 높다.
- **소코반** — 상자를 밀어서 노란 원에 모두 올린다. 당길 수는 없다(`U`로 무르기는 된다).
  적은 수로 풀수록 점수가 높다.
- **테트리스** — 표준. 7-bag 랜덤, 착지 위치 미리보기, 좌우 2칸까지 벽차기, 지운 줄 수에 따라 100/300/500/800점,
  10줄마다 낙하 속도가 빨라진다.
- **수박게임** — 같은 과일 둘이 닿으면 다음 단계 하나로. 11단계.
  물리는 Verlet + 위치 보정(PBD)이라 튀지 않고 자연스럽게 쌓인다.
  점선 위에 과일이 1.6초 이상 얹혀 있으면 게임 오버.
- **Triple Town** — 6x6. 같은 것이 상하좌우로 3개 이상 이어지면 놓은 자리에서 한 단계 위로,
  연쇄된다. 풀 → 덤불 → 나무 → 오두막 → 집 → 저택 → 성 → 공중성.
  곰은 매 턴 빈칸으로 돌아다니고, 사방이 막히면 묘비가 된다. 묘비 3개 → 교회 → 대성당.
  판이 꽉 차면 끝.
- **Threes!** — 한 번에 한 칸씩만 민다. `1+2=3`, 그 뒤로는 같은 수끼리(3+3, 6+6 …).
  새 타일은 밀려 들어온 쪽 끝에 붙는다. 점수는 3 이상 타일만 3^(단계).

원작들의 정확한 점수표·확률표는 공개된 적이 없어 자체 값을 쓴다.

## 환경별로 다른 점

**투명도** — `-alpha`는 창 합성(compositing)을 하는 환경에서만 동작한다.
합성기가 없는 X 세션에서는 불투명하게 뜰 수 있다.

**`F8`** — 창이 작업표시줄로 내려가 있으면 tkinter는 키 입력을 받지 못한다.
그래서 OS에 직접 등록해야 하는데, 이건 윈도우에서만 된다(`ctypes` + `RegisterHotKey`).
다른 환경에서는 조용히 꺼지고, 작업표시줄 아이콘을 클릭해서 꺼내면 된다.

둘 다 윈도우에서 제대로 동작하므로, 회사 PC에서 쓸 거면 WSL이 아니라
**윈도우용 파이썬**으로 실행하는 편이 낫다.

```
py desk.py
```

### 복귀 단축키 바꾸기

`hotkey.py` 맨 위 한 줄만 고치면 된다.

```python
HOTKEY = "F8"
```

`"F8"`, `"Alt+\`"`, `"Ctrl+Alt+G"`, `"Shift+F9"` 처럼 쓰면 된다.
F1~F24 · 알파벳 · 숫자 · 기호 키를 지원하고, 조합은 `Ctrl` `Alt` `Shift` `Win`이다.

전역 단축키는 **PC 전체에서 한 프로그램만** 잡을 수 있다. 이미 다른 프로그램이
쓰고 있으면 등록에 실패한다 (이 PC에서는 `F9`와 `F12`가 이미 사용 중이었다).

그래서 등록에 실패하면 `FALLBACKS` 목록의 키를 순서대로 자동으로 시도한다.
실제로 어떤 키가 잡혔는지는 **게임 고르기 화면 맨 아래에 항상 표시된다.**
하나도 못 잡으면 빨간 글씨로 알려 주고, 그때는 작업표시줄 클릭으로 꺼내면 된다.

반대로, 잡는 데 성공하면 그동안 **그 키의 원래 기능은 다른 프로그램에서 안 먹는다.**

## 테스트

```bash
python3 smoke_test.py
```

규칙(합치기·줄 삭제·연쇄·곰), 물리(정착·병합·게임오버), 저장/복원 JSON 왕복,
아홉 게임의 렌더 경로, 내리기·꺼내기·최고 기록 유지, 그리고 **만들어 낸 레벨이
정말 풀리는지**(네모로직 논리 풀이 · 소코반 탐색 · Flood It 탐욕 풀이)까지 확인한다.

레벨 검증은 표본만 돌린다. 전수로 돌리려면:

```bash
python3 -c "
from games import nonogram as n
print(sum(n.line_solve(*n.make(s, i)[1:], s) == n.make(s, i)[0]
          for s in n.SIZES for i in range(n.LEVELS)))"
```
